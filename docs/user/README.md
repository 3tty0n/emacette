# User guide

emacette is a small, fast terminal editor with Emacs-style key bindings. This
guide covers installation, everyday editing, and the optional language
features. If you are looking for build and release information, see the
[development guide](../development/README.md).

New to emacette? Start with the [quick start](../../README.md#quick-start) and
[Key bindings](keys.md), then press `F1` inside the editor for an overview.

## Getting started

- [Installation](install.md) — prebuilt binaries, source installs, and the
  installer.
- [Key bindings](keys.md) — every key, regions, search, and minibuffer editing.
- [Commands](commands.md) — commands available through `M-x`.
- [Tabs](tabs.md) — work with several files at once.
- [tmux](tmux.md) — keep emacette's key bindings usable inside tmux panes.

## Configure and extend

- [Configuration](configuration.md) — global and per-language settings,
  auto-fill, and soft wrapping.
- [Languages](languages.md) — supported languages, formats, and detection rules.
- [Completion](completion.md) — minibuffer candidate lists and editor completion.
- [Spelling](spelling.md) — English spell checking for prose.
- [Language servers](lsp.md) — diagnostics and completion through an LSP server.

## Workflows

- [Git integration](git.md) — use emacette for commit messages and other
  `$EDITOR` prompts.

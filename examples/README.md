# Example configuration

`config` is an annotated emacette configuration file.

Copy it to one of these locations:

- `$EMACETTE_CONFIG`
- `$XDG_CONFIG_HOME/emacette/config`
- `~/.config/emacette/config`

Then uncomment the settings you want. Language-server commands are commented
out so the file works without installing every server.

The old `~/.config/nano-emacs/config` is not read.

See [Configuration](../docs/configuration.md) for every option.
